# PiQuest

> 단순 소스 코드 수정을 넘어, 실제 게임 개발 워크플로우 전체를 다루는 실험적 AI 에이전트.

**PiQuest**는 [Pi](https://github.com/badlogic/pi-mono) 기반의 게임 개발 AI 에이전트 프로젝트입니다. 단순 코드 생성을 넘어 엔진 실행 및 런타임 검증까지 수행하는 것을 목표로 합니다.

---

## 🎯 핵심 원칙

1. **소스 트리가 아닌 '게임 프로젝트' 단위 이해**: 코드뿐만 아니라 씬, 프리팹, ScriptableObject, 프로젝트 설정을 종합적으로 다룹니다.
2. **증거 기반 검증 (Evidence-Driven)**: "컴파일 성공 = 작업 성공"이 아닙니다. 런타임 로그, 화면 결과, 프로파일러 지표로 실제 동작을 검증합니다.
3. **특화 워크플로우 우선**: 복잡한 멀티 에이전트 구조를 먼저 도입하기보다 실질적인 워크플로우를 최우선으로 검증합니다.
4. **Unity 우선 실증**: Unity 환경에서 실용성을 확실히 검증한 후 일반화합니다.

---

## 🔄 검증 피라미드 (Verification Ladder)

작업 성격에 따라 가장 가벼운 단계의 검증 방식을 적용합니다.

1. 정적 / 구문 검증
2. Unity 컴파일 및 임포트 검증
3. 씬 / 프로젝트 로드 확인
4. Play Mode 실행
5. 제어된 런타임 상태 및 게임플레이 검증
6. 시각적 검사 (스크린샷)
7. 프로파일링 및 성능 비교

---

## 🚀 핵심 워크플로우

- **게임플레이 구현 및 디버깅**: 로직 구현 및 런타임 예외 추적·수정
- **엔진 아티팩트 제어**: 씬, 프리팹, ScriptableObject 설정 및 직렬화 참조 관리
- **성능 최적화**: 프로파일러 지표(CPU/GC/Memory)에 기반한 최적화
- **기획 및 리소스 통합**: UI 조정 및 아트 에셋 씬 반영
